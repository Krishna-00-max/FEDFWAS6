# FoodShare Website

A beginner-friendly static website recreated from the supplied FoodShare UI reference.

## Modules included

1. Home Page
2. Donor Registration
3. Donate Food
4. Find Food (Search & Filter)
5. Request Food
6. Donation Status Tracking
7. Dashboard
8. Awareness / About
9. Contact / Feedback

## Files

- `index.html` — all page/module HTML
- `styles.css` — responsive CSS
- `script.js` — basic JavaScript interactions
- `assets/reference.png` — supplied reference image

## How to run

1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge/Firefox.
3. No server, database, framework, npm, or internet connection is required.

## JavaScript demo features

- Navigation between all modules
- Responsive mobile menu
- Donor registration success message
- Food donation form
- Food search/filtering
- Request Food workflow
- Donation status progression
- Dashboard counters
- Contact/feedback form
- Toast notifications

This is a front-end demo. Form data is not sent to a real server or database.
